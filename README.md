# SHIKI-CocktailGimmik-Recipe
# v1.5.2 全183レシピ

既存183レシピの名称・材料・配合・指定グラスを維持し、ブドウ・マンゴージュースを使う10レシピを追加しています。材料を一度ずつUseで注ぐと自動で規定量が入り、注ぎ続けても重複追加しません。途中の材料から候補を選び、材料が揃った時点で規定配合に整えます。候補が変わると途中の仮量も変わります。レシピにない組合せはHOUSE MIXとして従来の連続注液になります。

分量は1杯分のmlです。氷・融解水を含む容量上限を超える場合は、全材料を同比率で縮小します。融解水を材料のWATERとして判定しません。氷は空のグラスにトング1回で規定数を先に入れます。

シェイカーには氷3個を先に入れ、シェイクする材料だけを一度ずつ注ぎます。Useで蓋を閉め、Useを押しながら6ストロークで混合し、Useで注ぎ口を開けてグラスに注ぎます。炭酸の後入れは受け側グラスで行います。

複数材料のハイボールとステア指定レシピでは、最後にバースプーンを持ち、Useを押しながら先端をグラスの口へ近づけて約1秒混ぜます。スプーンを自分で回す必要はありません。氷入りの場合はカラカラと音が鳴ります。単体飲料には混ぜる操作を要求しません。
