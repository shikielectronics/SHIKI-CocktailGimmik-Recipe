# v1.7.0 全280レシピ

複数材料は材料を一度ずつUseで注ぐと自動で規定量が入ります。単体飲料は同じ材料を二回に分けて注ぐと、初回が半量、二回目で1杯分になります。同じUseを押し続けても二回分にはなりません。ボムの各材料は従来どおり一回ずつ30mlです。途中の材料から候補を選び、材料が揃った時点で規定配合に整えます。候補が変わると途中の仮量も変わります。レシピにない組合せはHOUSE MIXとして従来の連続注液になります。

分量は1杯分のmlです。氷・液体を含む容量上限を超える場合は、全材料を同比率で縮小します。

シェイカーには氷3個とシェイクする材料だけを一度ずつ入れます。氷と材料はどちらを先にしてもかまいません。Useで蓋を閉め、蓋を閉めたままUseを押さずに10ストロークで混合し、Useで注ぎ口を開けてグラスに注ぎます。炭酸の後入れは受け側グラスで行います。

複数材料のハイボールとステア指定レシピでは、最後にバースプーンを持ち、Useを押しながら先端をグラスの口へ近づけて約1秒混ぜます。スプーンを自分で回す必要はありません。氷入りの場合はカラカラと音が鳴ります。単体飲料には混ぜる操作を要求しません。

日本酒・白酒・焼酎ボトルとエナジー缶は最初のUseで開栓する。Useを一度離してから次のUseで注ぐ。開栓Useを押したまま持ち続けても液体は出ない。カンパニは他の注ぎ口付きボトルと同じ1回Useで注ぐ。手放して30秒で棚へ自動的に戻ると蓋も閉まる。

飲み切ったグラスは材料・完成状態・注入履歴がリセットされ、残った氷を使って再度作れます。飲み物は傾けてもこぼれず、Useで飲みます。エスプレッソだけのコーヒーカップは、傾けて開いたシェイカーの口へ合わせUseすると材料として移せます。ボトル、シェイカー、トング、バースプーン、材料トレイは手放して30秒で定位置へ戻ります。

徳利は日本酒を二回で180ml入れ、素早い二回Useで専用のお猪口を一個呼び出します。一回Useでそのお猪口に45mlまで注ぎます。お猪口はUseで飲め、空になればまた徳利から注げます。徳利を手放してMasterやシンクへ返すと専用お猪口も消えます。

### 001. ウイスキーエナジー（WHISKY ENERGY）

- 材料：ウイスキー 30ml、エナジードリンク 120ml
- グラス：ハイボール。受け側の氷：3個（トング1回）。
- 作り方：空のグラスに氷3個→材料を各1回Useで注ぐ（自動定量・自動配合）→バースプーンのUseを押しながら先端をグラスへ近づけ、約1秒混ぜる。
- ガーニッシュ：レモン：最後にトングでグラスの縁へ添える（飾り。配合は変わらない）。果汁をボトルで入れる場合も同じ配合。最初の果実・葉の後、氷→残りの材料の順に作れる。仕上げは必須ではない。
- 判定：材料の組合せ／規定配合へ自動調整。配合：配布ギミック用の規定配合。
